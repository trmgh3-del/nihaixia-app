# 倪师经方 · UniApp App

这是一个基于上游 [nihaixia 知识库](https://github.com/jangviktor-web/nihaixia) 的 UniApp 学习型中医知识库应用。

完整的导入、运行、数据重建、规则测试和 HBuilderX 验收说明，请参阅：

- [README_导入运行说明.md](./README_导入运行说明.md)
- [HBuilderX 多端验收清单](./tools/HBUILDERX_TEST_CHECKLIST.md)

当前数据包含 351 首方剂、471 味本草、301 个穴位、5 个藏象实体和 140 条可执行辨证规则。

> 本项目用于中医知识学习和辨证思路演示，不构成医疗诊断、处方或自行用药/针灸建议。
